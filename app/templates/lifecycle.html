⚡ Core Architecture in Brief
  • Supervised Classification: FreshIQ maps continuous multi-sensor streams (Temp, Humidity, Light, CO2) directly to binary shelf-life states (Fresh vs Spoiled).
  • End-to-End Request Trace: HTTP POST → Schema Validation → Dew Point & VPD Psychrometric Math → StandardScaler → One-Hot Encoding → Model Inference → JSON Response (<15ms).

📐 2. Supervised Learning: Linear Models

Closed-form normal equations, weight regularization penalties, and feature correlations.

Stage 2
⚡ Linear Principles in Brief
  • Closed-Form vs Iterative: Ridge Classifier solves closed-form normal equations directly via matrix inversion for instant computation. Logistic Regression iteratively optimizes cross-entropy loss via gradient descent.
  • L2 (Ridge) vs L1 (Lasso) Regularization: Ridge shrinks feature weights smoothly towards zero to prevent overfitting on sensor noise. Lasso forces less impactful coefficients exactly to zero for automated feature selection.
  • Logistic Sigmoid Mapping: Squashes linear combinations into calibrated probabilities between 0% and 100%, penalizing confident misclassifications heavily.
  • Feature Scaling: StandardScaler is mandatory so wide-range sensors (CO2 up to 500 ppm) do not dominate narrow-range sensors (Temperature 20–28°C).

🌲 3. Supervised Learning: Tree-Based Models

Recursive CART splits, Random Forest 300-tree bagging, boosting ensembles, and MDI feature importance.

Stage 3
⚡ Tree & Ensemble Principles in Brief
  • Decision Tree Splits: Greedily selects thresholds (e.g. CO2 > 350 ppm) that maximize impurity reduction, creating transparent rule sets that reflect post-harvest decay biology.
  • Random Forest (Bagging): Ensembles 300 de-correlated trees trained on bootstrap samples with random feature subsets, reducing variance and noise sensitivity without adding bias.
  • Boosting (AdaBoost & Gradient Boosting): AdaBoost successively re-weights hard boundary samples; Gradient Boosting fits successive shallow trees directly to residual errors.
  • Tabular Mastery: Trees handle sharp step transitions, non-linear sensor thresholds, and differing scales natively without requiring feature normalization.

⚡ Unsupervised Role in Brief
  • PCA Dimensionality Reduction: Compresses 4 sensor channels into 2 orthogonal principal components capturing 98.4% of total variance, enabling instant 2D cluster visualization.
  • K-Means Microclimates: Partitions raw unlabelled warehouse logs into 3 natural microclimates (Safe Cold, Transition, and Critical Spoilage) to verify real storage regimes.
  • DBSCAN Density Verification: Detects irregular, non-spherical clusters without requiring a fixed cluster count, isolating sensor noise.
  • Isolation Forest Spike Detection: Uses tree depths to isolate sudden sensor spikes (e.g. warehouse door left open) before downstream classification.

🎯 5. Model Evaluation, Selection & Calibration

Stratified cross-validation, Brier score probability calibration, and multi-model benchmarking.

Stage 5
⚡ Validation Discipline in Brief
  • Three-Way Split & Stratification: 80/20 train/test split with 5-fold cross-validation preserving the 56:44 Fresh/Spoiled class balance across every fold.
  • F1-Score over Raw Accuracy: On imbalanced produce batches, naive accuracy masks false negatives. We benchmark primarily against F1-score (harmonic balance of precision & recall).
  • Platt Scaling (Sigmoid Fit): Calibrates raw margin outputs so an 80% model confidence score corresponds to an authentic 80% real-world probability (Brier Score: {{ lifecycle.m5_evaluation_calibration.brier_score_calibrated }}).
  • Statistical Rigor: McNemar's paired test confirms Random Forest's 99.7% F1 performance represents genuine statistical dominance over linear baselines (p < 0.001).

Production pipeline packaging, sub-15ms REST latency, and Kolmogorov-Smirnov drift monitoring.

Stage 6
⚡ Production Pillars in Brief
  • Notebook-to-Production Modularization: Pipeline code is decoupled from notebooks into production Python modules (src/config.py, src/preprocessor.py, src/predictor.py) with strict typing and schema validation.
  • High-Throughput REST Serving: Flask endpoints deliver average inference latency of {{ lifecycle.m6_engineering.average_latency_ms }} ms with throughput exceeding {{ lifecycle.m6_engineering.throughput_samples_per_sec }} samples/sec.
  • Kolmogorov-Smirnov Drift Test: Statistical two-sample tests compare incoming sensor distributions against training baselines (p < 0.05 triggers drift alert).
  • Continuous Retraining Webhook: Live /api/retrain re-evaluates candidate models against the champion with automated zero-downtime promotion.
